Plugin repositories

Paste a repository address: a GitHub repository (github.com/owner/name, which must contain a repo.json) or a direct link to a repository JSON file. Every plugin they list shows up under Browse.

    Local plugin folders

    For making your own plugins: a folder with a manifest.json and index.html. Local plugins load straight from the folder and never update from a repository.

      Daeva Hub updates

      Daeva Hub updates itself: it looks for a new version when it starts and every few hours, downloads it in the background, and asks you to restart. If you don't, it installs the next time you quit.

      About

      Plugins run in their own windows, sandboxed, with no internet access, and never touch the game. Only install plugins from repositories you trust. Daeva Hub checks for plugin updates every time it starts.

      The DPS meter's capture code comes from A2Tools (GPL-3.0). It needs Npcap, reads the game's network traffic, and never sends anything anywhere.
